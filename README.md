# ▶️ How to Run a Program

### 1. Clone the repository

```bash
git clone <repository-url>
```

### 2. Open the project

```bash
cd OOPS-CPP-Unit-II
```

### 3. Navigate to the required program

Example:

```bash
cd Unit_2/Program_1
```

### 4. Compile

```bash
g++ program_1.cpp -o program
```

### 5. Run

On Windows:

```bash
.\program.exe
```

On Linux/macOS:

```bash
./program
```

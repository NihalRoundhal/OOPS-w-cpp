## 📚 Unit II — Inheritance

### What is Inheritance?

Inheritance is an OOP mechanism through which one class can acquire and extend the properties and behavior of another class.

* **Base Class** → Parent / Superclass
* **Derived Class** → Child / Subclass

For example:

```text
Vehicle
   │
   └── Car
```

A **Car is a Vehicle**, which represents an inheritance relationship.

## 🌳 Types of Inheritance

### Single Inheritance

```text
Base
  │
  ▼
Derived
```

### Multilevel Inheritance

```text
Base
  │
  ▼
Derived
  │
  ▼
Further Derived
```

### Multiple Inheritance

```text
Base 1     Base 2
   \       /
    \     /
     Derived
```

### Hierarchical Inheritance

```text
       Base
      /    \
     ▼      ▼
 Derived  Derived
```

### Hybrid Inheritance

Hybrid inheritance combines more than one type of inheritance.
